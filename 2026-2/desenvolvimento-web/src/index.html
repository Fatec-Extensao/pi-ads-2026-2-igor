Apresentação da pesquisa

Este projeto apresenta um sistema para organizar pesquisas de satisfação por categorias de participantes, questionários e respostas. O objetivo é centralizar o cadastro das pesquisas, permitir respostas por senha anônima e apresentar indicadores para acompanhamento.

O protótipo demonstra a estrutura das telas e a navegação entre funcionalidades. As telas usam HTML, CSS e JavaScript. Os formulários demonstram os fluxos com dados fictícios, sem cadastro real ou persistência.

Acessar o sistema

Objetivos

  • Organizar pesquisas e categorias de participantes.
  • Cadastrar perguntas, alternativas e questionários.
  • Permitir o fluxo de solicitação de senha e resposta.
  • Acompanhar a participação e visualizar relatórios.
