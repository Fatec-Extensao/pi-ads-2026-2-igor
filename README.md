# pi-ads-2026-2-igor

Repositório acadêmico do Projeto Integrador do curso de Análise e Desenvolvimento de Sistemas da FATEC Lins.

## Semestre 2026-2

- [Documentação e organização das entregas de 2026-2](./2026-2/README.md)
- **Projeto:** Sistema Web para Gestão de Pesquisas por Questionários
- **Aplicação publicada:** [Abrir o protótipo no GitHub Pages](https://fatec-extensao.github.io/pi-ads-2026-2-igor/) — demonstração acadêmica de interface, sem coleta real de dados.

O repositório reúne os artefatos acadêmicos de Engenharia de Software, Banco de Dados, Desenvolvimento Web e Compliance e Segurança. A [visão geral das entregas, limites e evidências](./2026-2/README.md) indica o que está documentado e o que ainda depende de decisão ou produção do grupo.

O site público é um protótipo estático. Não existe integração operacional entre a interface, o banco de dados ou serviços de autenticação; use apenas os dados fictícios incluídos na demonstração. Consulte também a [documentação de Desenvolvimento Web](./2026-2/desenvolvimento-web/README.md).
